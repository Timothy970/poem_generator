# **App Name**: Floral Muse

## Core Features:

- Theme Input: Input field to enter the poem's theme.
- Style Selection: Dropdown list to select a poem style (e.g., haiku, sonnet, free verse).
- Poem Generation: AI-powered tool to generate a poem based on the user-provided theme and selected style.
- Content Layout: Displays user inputs and generated poem in a split-screen layout.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) for a gentle and creative feel.
- Background color: Very light grayish-lavender (#F7F7FC), providing a calm backdrop.
- Accent color: Muted rose (#E0BBE4) to highlight key interactive elements.
- Use clear and readable sans-serif fonts for user inputs and poem text to ensure easy readability.
- Split-screen layout with input fields on the left and poem display on the right. 
- Subtle floral icons used sparingly for decorative accents.
